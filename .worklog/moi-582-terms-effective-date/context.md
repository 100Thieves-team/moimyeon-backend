# 컨텍스트

- 이슈: https://linear.app/100-thieves/issue/MOI-582
- 상위: https://linear.app/100-thieves/issue/MOI-576
- 직접 요구사항: “7일 0시로 변경해줘.”

직전 구현은 두 문서를 ACTIVE로 설정했지만 2026-10-08 00:00 Asia/Seoul까지 API에서 제외한다. 사용자 요청에 따라 10월 7일 0시로 앞당겨 변경 이후 즉시 사용하도록 한다. 선택된 날짜는 현재 동의 생성 시각이나 과거 회원의 동의를 뜻하지 않는다.

현재 TermsFinder·TermsAgreementManager는 한국 시행시각 기준 종류별 최신 ACTIVE를 선택한다. 데이터 정정만 필요하며 서비스 로직은 유지한다. 실제 본문의 미확정 운영 사실과 나머지 정책은 변경하지 않는다. 아직 동의되지 않은 예약 문서만 정정하고, 실제 동의 이력이 있으면 새 버전 판단이 필요하므로 마이그레이션을 중단한다.

원본 Wiki는 이전 작업에서 인증 때문에 읽지 못했다. 이번 날짜 변경은 사용자 직접 지시에 충분히 정의되어 있으며 원본 대조·명세 수정 완료를 주장하지 않는다. 운영 DB는 직접 수정하지 않고 배포의 Flyway를 사용한다.
