# 약관 v1.1 시행일 정정

사용자 요청으로 이용약관과 개인정보 처리방침 v1.1의 시행시각을 2026-10-08 00:00에서 2026-10-07 00:00 Asia/Seoul로 앞당긴다. API는 이미 DB의 시행시각을 기준으로 문서를 선택하므로 서비스 코드 변경 없이 데이터만 정정한다.

배포 시 새 Flyway V35가 대상 두 문서의 ID·종류·버전·상태·기존 시행일과 동의 이력 부재를 확인한다. 두 문서가 모두 조건을 만족하면 시행시각과 본문 날짜를 한 UPDATE로 바꾼다. 조건이 다르거나 v1.1 동의가 존재하면 어떤 문서도 정정하지 않고 중단한다.

변경 전에는 10월 8일 0시까지 v1.0을 제공한다. 변경 후에는 이미 지난 10월 7일 0시를 기준으로 v1.1을 즉시 조회하고 신규 가입 시 해당 버전을 기록한다. 문서 ID·버전과 v1.0·기존 동의 이력은 그대로 유지하며 과거 시점의 동의를 생성하지 않는다. API 경로·응답 필드·Swagger 예시는 변경하지 않는다.

전체 테스트 1,444개와 ktlint가 통과했다. 실제 MySQL에서 날짜 정정, 기존 이력 보존, 동의 이력이 있는 경우 무변경 중단, 재실행을 검증했다. 실제 시드를 사용하는 조회·가입 테스트도 한국시간 시행 직전·정각·직후를 확인했다. 코드·DB·QA 읽기 전용 리뷰에 필수 수정 사항은 없다.

원본 Wiki는 앞선 작업의 인증 제한으로 미확인이며 이번 변경은 사용자 직접 요청에 따른다. 기존 문안의 운영 사실 확인과 후속 기능 범위는 [MOI-576](https://linear.app/100-thieves/issue/MOI-576)에 유지한다. [MOI-582](https://linear.app/100-thieves/issue/MOI-582)가 이번 날짜 정정 범위다. 운영 DB 수동 수정이나 seed 수동 실행은 하지 않는다. 기존 시행시각 이후로 배포가 늦어지면 미동의 예약 문서라는 전제를 다시 확인한다.
