# 리뷰 수정 커밋과 전체 검증

- [x] [전체 계획](../MOI-549-pr-scope/plan.md)의 리라이트·최종 검증 단계 승인.

리뷰 수정은 기존 관심사의 커밋에 amend 또는 fixup/autosquash로 반영한다.
관측한 원격 head를 명시한 lease로만 push하며 보호 브랜치는 제외한다.
의도한 amend가 계보 분기라는 이유로 거부되지 않도록 사전 증거·range-diff를
확인하고, 근거 없는 분기는 중단한다. 파일 내용 비교와 최신 head 검증까지 포함한다.

임시 bare 저장소에서 최신/이전 커밋 수정, 원격 선행 변경과 background fetch 후
명시적 lease 거부, main/dev 훅 차단, 하위 스택의 변경 보존을 확인한다.
실제 원격에서 시험용 리라이트를 하지 않는다. PR 생성 전 전체 산출물·검증 기록을
마치고, 이후 증거는 저장소 밖에서만 다룬다.

이번 변경은 하네스 규칙으로 제품 명세·ADR이나 Wiki 갱신은 필요하지 않다.

## 검증 결과

- 임시 bare Git에서 5개 리라이트 시나리오 통과. 최신 amend, 이전 fixup/autosquash,
  원격 선행 변경 뒤 fetch를 해도 명시적 lease 거부, main/dev non-fast-forward 차단,
  자식 PR의 고유 변경만 보존하는 재배치를 확인했다.
- range-diff가 작은 커밋을 삭제/추가로 표시할 수 있어 실제 tree diff도 함께
  확인하도록 절차를 보강했다. 명령 성공만으로 내용 일치를 판정하지 않는다.
- 전체 하네스 게이트 통과(파일 수/CI 계약 11개, 리라이트 5개, checkout pin 13개와
  기존 시크릿·프로파일·페어링 검사). 스킬 lint, 변경 Actions의 actionlint 1.7.12,
  배포·릴리스 계약 검사도 통과했다.
- 애플리케이션 코드·Gradle 구성은 변경하지 않았다. 첫 단계에서 실행한
  `./gradlew test ktlintCheck`는 205개 태스크를 실행하고 통과했다.
- 단계별 읽기 전용 QA에서 발견한 문제를 수정하고 재검토를 받았다.
  Wiki 작업의 근거 전달, 상대 eval 출력 경로, 미스테이지 rename 집계,
  설명 스킬의 경쟁 요청 음성 입력을 보완했다.
- 외부 Claude CLI 평가의 데이터 전송은 자동 승인 검토에서 거절되어 우회하지 않았다.
  네이티브 독립 세션의 양성·음성·경계 라우팅과 정상/실패 가상 시나리오로 대체했다.
  외부 CLI 동작 성공이나 실제 Wiki·Artifact 쓰기 성공으로 집계하지 않는다.

PR 전 커밋·파일 수와 공유 문서를 최종 확인한다. PR 생성 뒤의 링크·CI·리뷰 상태는
GitHub와 반환 메시지에서 관리하며 이 파일에 복제하지 않는다.
