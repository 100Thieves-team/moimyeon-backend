공개 목록은 status ACTIVE, effectiveFrom <= Asia/Seoul 시각인 문서 중 종류별 가장 최근 시행 버전이다. 동시 시행 충돌은 임의 선택하지 않고 E1203으로 드러낸다. 상세는 ACTIVE/DEPRECATED의 시행된 버전만 반환하며 DRAFT·미시행·삭제·부재는 404 E1202다. 경로 UUID 오류는 E400이다. 신규 가입 시 현재 SERVICE/PRIVACY 중 어느 하나라도 없으면 E1203으로 기록을 중단한다. 최신 문서가 required=false이면 과거 required=true를 다시 요구하지 않는다.

프런트 영향: 기존 목록 응답은 동일, 상세 링크로 termsId 사용 가능. 본문은 Markdown 문자열이며 초안은 공개하지 않는다. 새 테이블·관리자 편집/게시 API·재동의 게이트·이력서 제공 동의·파기 자동화는 범위 밖.

실행 결과: 구현·로컬 적재·테스트·리뷰 반영을 완료했다. 검증 근거는 verification.md, Wiki 확인 한계는 wiki-sync.md에 기록했다. 운영 DB 직접 적용은 범위 밖이다. 후속 사용자 요청으로 이슈 생성·연결과 커밋·PR 생성까지 진행한다.
