# Bedrock Claude 3.5 Sonnet 전환 미결정 사항

## eval 후 결정

- 대표 도로명 패턴 밖의 비정형 주소, 비라벨 학번과 문맥형 개인정보는 현재
  정규식으로 탐지하지 못한다. 실사용 데이터에서 필요성이 확인되면 별도
  탐지 전략을 결정한다.
- 이미지 전용 PDF는 OCR 없이 거부한다. 업로드 API는 요약 실패 상태만
  제공하므로 사용자에게 텍스트 PDF 재업로드를 안내하는 UX는 프론트와
  별도로 결정한다.
- live eval의 prompt-injection 케이스는 영문 지시와 표식 한 종류다. 한국어
  지시, `</resume>` 탈출, 프롬프트 공개 유도와 fixture별 필수·금지 사실 판정은
  후속 eval 셋 확장 대상으로 남긴다.
- 10MB·50페이지·60,000자 상한과 연산별 deadline 검사는 PDFBox 처리 확장을
  제한하지만, 거대한 단일 압축 문자열의 해제 임시 메모리는 하드 제한하지
  않는다. 운영 heap 이상 사례가 확인되면 별도 worker 격리나 동시성 제한을
  도입한다.
- system prompt의 자연어 금지 표현과 결정적 출력 검증 정규식은 표현 목적이
  달라 별도로 유지한다. 금지 표현을 변경할 때 두 목록을 함께 갱신하도록
  단일 정책에서 파생할지는 후속 리팩터링에서 결정한다.
