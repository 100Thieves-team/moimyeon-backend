# 이력서 요약 모델·파이프라인 비교 결과

실행일: 2026-09-03

## 비교 대상

동일한 합성 PDF 6종을 케이스별 3회 실행했다. 실사용자 문서는 사용하지 않았다.

| variant | 모델 | 전처리·프롬프트 |
| --- | --- | --- |
| Sonnet 5 release baseline | `global.anthropic.claude-sonnet-5` | 배포 중인 구 프롬프트, 4.5MB 이하 PDF document 직접 입력 |
| Claude 3.5 legacy pipeline | `anthropic.claude-3-5-sonnet-20240620-v1:0` | 구 프롬프트·구 PDF 입력을 유지해 모델 효과만 분리 |
| Claude 3.5 text preprocessing | `anthropic.claude-3-5-sonnet-20240620-v1:0` | 서버 텍스트 추출·자원 제한·PII 입출력 마스킹·평가 표현 금지 |

공통 생성 설정은 temperature 0.1, max-tokens 300이다. baseline·legacy의
호출 제한은 30초, candidate는 20초이며 candidate 전체 처리 예산은 45초다. 원본 결과는
`evals/raw/bedrock-model-comparison-20260903.csv`에 로컬 보존한다.

## 결과

| 기준 | Sonnet 5 release | Claude 3.5 legacy | Claude 3.5 text preprocessing |
| --- | --- | --- | --- |
| 정상 응답 | 0/18, account 403 | 18/18 성공 | 텍스트 15/15 성공, 이미지 전용 3/3 사전 거부 |
| 전체 판정 | 가용성 0% | 9/18 통과 | 18/18 통과 |
| 성공 호출 평균 지연 | 해당 없음 | 2,538ms | 2,730ms |
| p95 | 418ms 뒤 403 | 5,029ms | 8,853ms |
| 입력 / 출력 토큰 | 0 / 0 | 79,052 / 1,782 | 104,395 / 1,559 |

Sonnet 5 baseline은 구 릴리스 묶음 그대로 재현했지만 계정 agreement가 없어
모든 호출이 403으로 실패했다. 따라서 모델 품질 비교는 동일 Claude 3.5
모델에 구/신 파이프라인을 적용한 ablation으로 분리했다.

구 파이프라인은 이미지 전용 PDF를 안내문으로 성공 처리했고, 장문·일반
케이스에서 `풍부한 경험`, `전문성`, `강점으로 보입니다` 같은 근거 없는
평가 표현 때문에 9건이 실패했다. 새 파이프라인은 이미지 전용 PDF를 모델
호출 전에 거부하고 평가성 표현 검사를 포함해 18건을 모두 통과했다. 중간
실행에서 장문 응답 2건의 평가 표현 위반을 발견해 출력 검증과 최대 1회
재생성을 추가했다. 최종 실행에서는 장문 1건을 한 번 재생성한 뒤 전부 합격했다.

## 안전성 경계

- 문서 텍스트는 `<resume>` 데이터 경계에 넣기 전에 XML escape한다.
- 문서 안의 명령을 따르지 않는 system 규칙과 인젝션 표식 검사를 유지한다.
- 이메일·전화·주민등록번호, 대표 도로명 주소와 라벨이 있는 주소·학번을 입력과 출력에서
  모두 마스킹한다.
- 결과가 한국어 1~2문장이 아니거나 평가 표현을 포함하면 최대 한 번 재생성하고,
  재차 위반하면 요약 실패로 처리한다.
- PDF는 최대 50페이지·추출 문자열 60,000자로 제한한다. 요청 시작 시 만든
  45초 monotonic deadline을 S3 I/O와 생성기가 공유하고, 회당 20초 호출을
  마칠 시간이 남을 때만 모델 호출을 시작한다.
- Bedrock invocation logging은 2026-09-03 계정 조회 결과 비활성 상태다.
- OCR과 raw PDF fallback은 사용하지 않는다.

## 결론

Claude 3.5 Sonnet In-Region과 새 텍스트 전처리 묶음은 현재 eval을 통과했다.
정상 Unicode로 잘못 매핑된 glyph와 정규식이 인식하지 못하는 자유형 PII는
잔여 위험으로 남는다.
