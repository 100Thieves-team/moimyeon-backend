# MOI-497 미결정 사항

- **최대 이력서 보관 개수의 문서 불일치**: MOI-485 화면 상단은 최대 5개로
  표시하지만 현재 API 계약·도메인 코드는 최신 PRD 기준 10개다. 기본 지정
  API와 무관하므로 이번 이슈에서 바꾸지 않는다. 제품 기준을 별도로 확인해
  화면 또는 API 계약 중 하나를 후속 정리해야 한다.
- **MySQL initdb 한글 인코딩 확인**: 검증용 `mysql:8.0` 컨테이너가
  `data-local.sql`을 초기화할 때 한글 닉네임을 mojibake로 저장해 개발 세션
  발급이 E1005로 실패했다. 검증 DB에서는 UTF-8 바이트로 바로잡아 진행했다.
  기존 docker-compose 최초 초기화에서도 재현되는지 별도 확인이 필요하다.
