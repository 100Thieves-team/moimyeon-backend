# MOI-522 하네스 log 기록 개선

## 계획

- [x] SHA 기반 `ship-pr` 재실행 계약을 Git·PR 상태 조회로 교체
- [x] worklog와 전역 하네스 정책에서 버전 관리 메타데이터 복제 금지
- [x] 열린 PR의 리뷰 산출물·실패 기록을 저장소 밖으로 분리
- [x] 기존 결정의 대체 관계와 이번 선택 이유 기록
- [x] 스킬 lint·하네스 게이트·문서 정합성 검증

체크박스는 사람의 단계 승인 기록이므로 실행 완료만으로 표시하지 않는다.

## 검증 기준

- `ship-pr`가 PR 생성 뒤 리뷰 반영 외에는 작업 트리 수정을 요구하지 않는다.
- 열린 PR의 리뷰 patch는 저장소 밖 임시 경로에 생성하고 위임 뒤 제거한다.
- 열린 PR의 읽기 전용 검증·리뷰는 시작과 종료 시
  `git status --porcelain --untracked-files=all`이 모두 비어 있어야 한다.
- 열린 PR도 현재 head 대상으로 검증·리뷰 게이트를 다시 통과해야 하며,
  깨끗한 작업 트리, 로컬/PR head 일치, 해당 head의 체크 성공까지 확인한 뒤
  리뷰봇 대응 단계를 재개한다.
- 하네스 스킬 lint와 결정론 게이트가 통과한다.

## 승인과 검증

- 2026-09-20 사용자가 PR 이후 리뷰 반영 외 작업 트리 무변경 원칙을 확인하고
  PR 생성까지 진행하도록 승인했다.
- `./gradlew test ktlintCheck` 통과.
- skill quick validation, 전체 스킬 lint, 하네스 결정론 게이트 통과.
- 독립 QA 재검토 PASS, 필수 지적과 coverage gap 없음.
