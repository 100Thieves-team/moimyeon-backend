# MOI-522 결정 기록

## 재실행 증거는 Git과 PR의 현재 상태에서 읽는다

- 날짜: 2026-09-20
- 내용과 이유: 추적 파일에 현재 HEAD를 기록하면 그 파일을 커밋하는 순간
  HEAD가 다시 바뀌어 자기참조가 생긴다. `ship-pr`는 열린 PR을 재개할 때마다
  현재 head 대상으로 검증·리뷰 게이트를 다시 수행한다. Git과 PR에서 clean
  작업 트리, 로컬/PR head 일치, 같은 head의 체크 성공도 조회해 재개 가능
  여부를 fail-closed로 판정한다. CI 성공을 로컬 리뷰 증거로 대신하지 않는다.
  worklog에는 요구사항·결정·승인·검증 결과를 PR 생성 전까지만 남긴다. PR
  이후 리뷰 입력은 저장소 밖 임시 patch를 쓰고, 실패와 검증 결과는 반환
  메시지로만 보고한다. 열린 PR의 읽기 전용 검증·리뷰는 clean 상태에서만
  시작하고 종료 시에도 clean이어야 한다. dirty 상태는 리뷰 지적을 반영하는
  흐름으로 확인된 경우에만 허용한다.
- 대안: push 뒤 plan.md에 SHA를 갱신하는 기존 방식은 기록용 후속 커밋을
  반복해서 만들므로 폐기한다. 별도 상태 파일도 같은 자기참조와 동기화 문제를
  옮길 뿐이라 도입하지 않는다.
