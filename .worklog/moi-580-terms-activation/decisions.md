# 결정

## 미동의 초안만 갱신
- 날짜: 2026-10-07
- 내용과 이유: v1.1은 아직 공개·동의되지 않은 초안이므로 같은 식별자로 최종 문안을 반영한다. 두 문서가 모두 예상 DRAFT이고 동의 이력이 전혀 없을 때만 한 UPDATE로 전환한다. 전제가 깨지면 새 버전이 필요하므로 자동 덮어쓰기를 중단한다.
- 대안: 기존 v1.1을 그대로 두고 v1.2를 추가하는 방법은 미발행 문서를 불필요하게 남기므로 채택하지 않았다.

## 시행일과 사실 확인의 구분
- 날짜: 2026-10-07
- 내용과 이유: 사용자는 후속 결정을 운영하면서 바꾸기로 했고 정식 발행을 요청했다. 확정된 시행일을 유지하고 실제 처리 사실의 미확정 표시는 보존한다. ACTIVE는 API 공개 상태이며 법률상 고지 요건의 충족을 인증하는 상태가 아니다.

## 배포와 롤백의 하한
- 날짜: 2026-10-07
- 내용과 이유: v1.0과 v1.1이 동시에 ACTIVE인 예약 발행은 MOI-575의 종류별 최신 시행 버전 선택 로직이 필요하다. 같은 DB를 읽는 모든 앱에 이 로직이 적용된 뒤 배포하고, 그 이전 앱으로 롤백하지 않는다. 직전 앱으로 롤백해도 발행 데이터는 남는다.
