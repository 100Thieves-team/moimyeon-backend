# MOI-532 결정 기록

## DR-001 — 직접 완료 시 확정 참여자 전원을 출석 처리한다

- 결정일: 2026-09-22
- 결정: 진행 확정 당시 `JOINED` 참여자 전원에게 `ATTENDED` 출석을 생성한다.
- 기록자: 확정을 실행한 방장
- 기록 시각: `CONFIRMED`·`COMPLETED` 상태 로그와 같은 확정 처리 시각
- 이유: 룸이 즉시 `COMPLETED`가 되어도 완료 후 후기 작성과 출석 기반 신뢰 통계가 동작해야 한다.
- 영향: 별도 출석 입력 없이 전원 출석으로 간주되므로 실제 출석 확인 절차는 생략된다.
