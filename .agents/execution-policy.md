# 실행 정책 (원본 — 런타임 참조 문서가 아니다)

이 파일은 스킬이 링크해 읽는 문서가 아니라 **규칙의 원본**이다 (DR-020).
런타임 배포처: 체크포인트·재실행·재시도 상한은 각 워크플로우 SKILL.md의
해당 단계에 인라인, "모호하면 질문"은 AGENTS.md. 규칙을 고치면 배포처도
함께 고친다 — 인라인 누락은 스킬 lint(Step 5)가 검사한다.
근거: [.worklog/MOI-474/decisions.md](../.worklog/MOI-474/decisions.md)의 DR-005·007·009·020.

## 모호하면 질문한다

판단이 어려운 결정(요구사항 해석, 설계 선택지, 영향 범위 불확실)은 추측으로
진행하지 말고 그 지점에서 턴을 끝내 사람에게 질문한다. 자율 결정이 목표가
아니다 — 모호한 결정의 에스컬레이트가 워크플로우의 일부다.

## 체크포인트

- SKILL.md 단계 중 `[체크포인트]` 지점에서는 산출물을 제시하고 **턴을 끝낸다**.
  사람 승인 없이 다음 단계로 넘어가지 않는다.
- 사용자가 "끝까지 진행해" 등으로 명시하면 체크포인트를 건너뛴다.
- `.worklog/{작업키}/plan.md`의 체크박스 `[x]`는 사람이 승인한 단계에만 표시한다.

## 재시도 상한

| 루프 | 상한 |
| --- | --- |
| AI 리뷰 지적 반영 | 2회 |
| 테스트 실패 수정 | 3회 |
| 리뷰봇 커멘트 대응 | 2회 |

상한 도달 시 plan.md 해당 단계에 `실패(재시도 n회 소진): 사유`를 기록하고
턴을 끝내 사람에게 알린다. 조용히 계속하거나 조용히 포기하지 않는다.

## 재실행 분기

- `.worklog/{작업키}/`가 있으면: plan.md 체크박스로 마지막 승인 지점을 판별하고
  그 다음 단계부터 재개한다. 기존 산출물 파일은 덮어쓰지 말고 차분만 수정한다.
- 없으면: 초기 실행이다. .worklog 디렉토리와 plan.md부터 만든다.

## 위임

- 서브에이전트 위임 프롬프트에는 반드시 명시한다: 역할 계약 파일 경로
  (`.agents/agents/…`), 입력 파일 경로(`.worklog/…`), 출력 형식.
- 위임 결과는 반환 텍스트로 받고, 다음 단계가 소비할 내용은 worklog 파일로
  남긴다.
