# worklog 기록 양식

파일 계약은 [worklog/README.md](../../../../worklog/README.md) 참조.

## decisions.md 항목

```markdown
## {결정 한 줄}
- 날짜: YYYY-MM-DD
- 내용과 이유: {무엇을 왜 그렇게 했나 — 코드만 봐서는 알 수 없는 배경}
- 대안: {검토했다 버린 것, 이유}
```

코드로 표현되는 내용은 적지 않는다. "왜"만 적는다.

## tbd.md 항목

```markdown
- [ ] {모호점 한 줄} — 배경: {어디서 막혔나}. PRD 반영 필요: 예/아니오
```

구현을 막는 항목이면 기록 후 턴을 끝내 사람에게 묻는다. 막지 않는 항목이면
기록만 하고 진행한다.
