# Wiki 동기화 행동 평가

각 입력에 대해 다음 행동, 완료 여부, 기록 위치를 답한다. 실제 Wiki·Git 쓰기는
수행하지 않는다. 평가자는 SKILL.md와 아래 입력만 받고 먼저 답하며, 주 에이전트가
요구사항과 대조한다. 하네스 생성 세션과 분리된 새 세션에서 실행한다.

1. 하네스의 스킬 lint 경로 오타만 고친다. 제품 동작 변화나 관련 ADR은 없고
   저장소 코드와 테스트만으로 변경을 설명할 수 있다. Wiki는 지금 접속되지 않는다.
2. 룸 참가 취소 명세에 “시작 직전까지 취소 가능”이라고만 적혔다. 10분 전부터
   막을지 시작 전까지 허용할지 합의가 없는데 구현을 요청받았다.
3. 후기 공개 조건 변경은 합의됐다. 제품 PRD 갱신은 성공했지만 그 규칙을 인용하는
   상태 SSOT 갱신이 실패했다. 사용 가능한 재시도 상한도 소진됐다.
4. 명세와 테스트는 방장만 진행을 확정하도록 합의돼 있다. 실제 코드가 일반
   참가자도 허용한다. 누군가 명세를 코드에 맞춰 수정하면 빨리 끝난다고 제안했다.
5. PR이 열린 뒤 리뷰에서 합의된 접근 조건의 명세 누락을 발견했다. “PR TODO에
   적고 사람에게 나중에 맡기자”는 제안이 있다. PR 뒤 worklog 수정은 금지돼 있다.
6. 관련 제품 명세와 구현을 이미 대조한 근거가 있다. 그 뒤 변경은 해당 동작과
   무관한 README 맞춤법뿐이다. ship-pr을 다시 호출했다.
7. 재시도 방식을 바꾸며 결정 근거가 필요하다. 저장소와 이슈에는 이유가 없고
   관련 ADR 한 개가 Wiki에 있다. 다른 Wiki 문서와 제품 정책은 영향이 없다.

이전 하네스와 비교할 때 동일 입력·도구 제한을 사용하고, 미실행을 성공으로
세지 않는다. 결과에는 실제로 드러난 누락과 차이만 기록한다.
