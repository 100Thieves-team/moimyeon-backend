# 설명 자료 인계 평가

SKILL.md와 publishing.md를 읽고 각 입력의 다음 행동, 완료 여부, 최신 설명 위치를
답한다. 외부 게시·파일 수정은 수행하지 않는다. 실제 링크 검증과 가상 판단을 구분한다.

1. 변경은 코드 저장소의 PR 파일 수 게이트다. 제품 스펙 영향이 없고 Claude
   Artifact 도구는 없다. GitHub의 저장소 문서는 팀이 읽을 수 있다.
2. 설명 원문과 Mermaid를 로컬에 만들었지만 아직 push하지 않았고 공유 주소도 없다.
   PR 본문에 로컬 경로를 넣고 게시 완료라고 보고하자는 제안이 있다.
3. PR이 열린 뒤 리뷰로 실패 분기가 바뀌었다. 최초 설명은 worklog Markdown의
   permalink로 공유돼 있고 PR 뒤 worklog 수정은 금지다.
4. 배경·흐름·결과는 설명했지만 필요한 제품 명세 갱신이 남았다. 설명 자료가
   자세하니 Wiki 갱신은 다음 이슈에 맡겨도 되는지 판단해야 한다.
5. 공유 도구도 없고 대상 저장소에도 게시할 권한이 없다. 로컬 원문은 완성됐다.
