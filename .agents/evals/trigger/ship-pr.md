# ship-pr 트리거 세트

- 양성 5: 커밋+PR 요청(p1·p2·p4), 리뷰봇 대응(p3·p5) — description의 두
  트리거 축을 모두 커버.
- 음성 5와 기대 라우팅: n1 구현(requirement-implementation), n2 컨벤션
  질문(스킬 없음 — 문서 답변), n3 QA 검토(qa-reviewer 위임 — 스킬 아님),
  n4 단순 git 조작(스킬 없음), n5 커밋 이력 요약(하네스 무관 소재 규칙,
  교훈 7).
- 경계 2: b1 "마무리하자"(모호 — 질문 또는 ship-pr 진입 모두 합리),
  b2 "테스트 통과했으면 바로 올려줘"(ship-pr 진입 + 체크포인트 생략 지시로
  해석 가능 — 어느 쪽이든 5단계 push 전 승인 확인이 관찰 포인트).

## 측정 전제 조건

ship-pr 1단계는 "변경분 검토"다. **워크트리에 커밋할 변경이 없으면** 스킬
진입 대신 "올릴 게 없다"는 상태 보고로 빠진다(2026-08-25 실측 — clean에서
미호출, dirty에서 4/4 호출). 이 세트를 측정할 때는 워크트리에 실제 변경을
만들어 둔다.
